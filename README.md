# Basque Cultures — English Workshop DBH4

A static student project website designed for GitHub Pages.

## Files
- `index.html` — home page
- `sports.html` — Sports section
- `festivals.html` — Festivals section
- `language.html` — Language section
- `mythology.html` — Mythology section
- `history.html` — History section
- `css/style.css` — visual design

## Student workflow
Each group contributes:
1. A blog post
2. A student video
3. Sources
4. A final answer to the driving question

The website intentionally contains placeholders rather than cultural content, so students create the content themselves.
